# 류시하 v6 — 옆으로 늘어나는 변형 수정

v5 AE 영상에서 특히 다리와 부츠가 옆으로 늘어나던 문제를 수정했습니다. 팔 변형의 영향 범위가 손 아래까지 이어졌고, 어깨에서 멀어질수록 옆으로 미는 양이 커지는 계산이 원인이었습니다.

- 팔 영향 범위를 어깨~손 주변으로 한정하고, 손 아래에서는 0으로 만듭니다.
- 옆으로 미는 전단 계산을 어깨 중심의 역회전으로 교체했습니다. 좌우 팔은 같은 원본 좌표에서 계산해 서로의 변형을 누적하지 않습니다.
- 하체에는 기존의 작은 무게 이동만 적용됩니다. 팔 때문에 다리와 부츠가 늘어나지 않습니다.
- v5의 연결된 어깨·배 구성과 16초 동작, 깜빡임을 유지합니다.

## 실행

두 ZIP을 같은 위치에 풀어 `Ryusiha_Natural_Motion_v6` 폴더를 합치세요. 다음 파일들이 같은 폴더에 있어야 합니다.

```text
Build_Natural_Motion_v6.jsx
Connected_Body_v6_part1.mov
Connected_Body_v6_part2.mov
assets/
```

AE에서 JSX를 실행하고 새 `RYUSIHA_NATURAL_V6_16s` 컴포지션을 확인하세요. v5 컴포지션은 자동 변경되지 않습니다. 두 MOV는 각각 8초이며 스크립트가 16초로 연결합니다. `Hair strength`는 조절 가능하지만 몸·팔·눈 동작은 영상에 고정되어 있습니다.

## 검증과 한계

하체 전체에 분포한 격자를 481개 시점에서 검사하여 팔 변형의 영향이 정확히 0임을 확인했습니다. 시작/끝 포즈가 동일하며 문제 구간의 부츠 형태도 시각적으로 확인했습니다. 두 MOV의 총 480프레임이 투명도를 포함해 렌더 원본과 일치하는지 검사했습니다. JSX 문법과 모의 구성을 확인했습니다. 실제 AE 실행·렌더링은 미검증입니다.

몸 영상은 무손실 PNG 코덱 MOV, 640×960, 30fps이며 AE 캔버스 1280×1920에서 확대됩니다. 원본 파츠보다 확대 시 부드럽게 보입니다. 기존 그림의 색 테두리와 복원 품질은 남아 있습니다. 비교 영상의 왼쪽은 사용자가 첨부한 v5 AE 영상, 오른쪽은 v6 참고 렌더링입니다.

## 재생성

Python 3, Pillow, NumPy, SciPy, FFmpeg 환경에서 `python3 render_preview.py`를 실행합니다. `body_sequence`에 생성되는 중간 PNG는 배포 패키지에 포함하지 않습니다. 몸 동작 수식은 `motion.json`, 머리카락 추종 수식은 JSX에도 포함되어 있습니다.
