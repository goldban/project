# 류시하 v7 — 이미지 보정과 하체 형태 보호

v6에서 허벅지 바깥쪽이 팔의 변형 범위와 겹쳐 늘어나는 문제가 남았습니다. 부츠 아래쪽 위주로 검사했던 범위를 골반·허벅지·다리·부츠 전체로 확대하고, 이미지의 실제 하체 윤곽에 따른 보호 영역으로 바꿨습니다.

## 수정 내용

- 몸 원본 이미지의 윤곽 보정본을 적용했습니다. 이미지 생성 도구로 편집한 결과이므로 일부 의상·피부의 세부 표현은 이전 버전과 다릅니다. 눈 깜빡임에는 기존 머리 포즈를 사용합니다.
- 골반부터 발까지는 원본 좌표에 고정합니다. 팔 변형, 상체 기울임, 확대·축소가 들어가지 않습니다.
- 하체와 경계 여백을 이미지 기준으로 보호합니다. 상체와 보호 영역 사이에는 부드러운 전환을 둡니다.
- 16초 동안 상체·팔·고개·머리카락과 눈 깜빡임으로 대기 동작을 표현합니다. 하체 자체는 움직이지 않습니다.

## 실행

두 ZIP을 같은 위치에 풀어 `Ryusiha_Natural_Motion_v7` 폴더를 합칩니다. 아래 파일들이 같은 폴더에 있어야 합니다.

```text
Build_Natural_Motion_v7.jsx
Connected_Body_v7_part1.mov
Connected_Body_v7_part2.mov
assets/
```

AE에서 JSX를 실행한 뒤 새 `RYUSIHA_NATURAL_V7_16s` 컴포지션을 확인하세요. 기존 컴포지션은 자동 변경되지 않습니다. 두 MOV는 각각 8초이며 스크립트가 이어 붙입니다. 몸 동작은 영상에 고정되어 있고 `Hair strength`만 별도로 조절할 수 있습니다.

## 검증·제한

보호 영역은 기존 하체 이미지의 알파 윤곽과 여백으로 정의했습니다. 허리·골반·허벅지·부츠의 보호 영역에서 원본 좌표가 유지되는지 확인하고, 렌더된 전체 480프레임의 보호 영역 RGBA 픽셀이 첫 프레임과 동일한지 검사했습니다. 두 MOV를 디코딩한 480프레임도 원본 PNG와 일치하는지 검사했습니다. 시작/끝 포즈, 8초 연결, JSX 문법 및 모의 AE 구성을 검사했습니다.

실제 AE 실행·렌더링은 이 환경에서 미검증입니다. 몸은 무손실 PNG 코덱 MOV, 640×960, 30fps이며 AE의 1280×1920 캔버스에서 확대됩니다. 원본 파츠보다 확대 시 부드럽게 보입니다. 보정 이미지에도 일부 색 테두리가 남아 있으며 완성된 Live2D 모델은 아닙니다.

## 재생성

Python 3, Pillow, NumPy, SciPy, FFmpeg 환경에서 `python3 render_preview.py`를 실행합니다. `assets/lower_body_reference.png`는 보호 영역을 정의하는 참조이며 화면 위에 별도 합성하지 않습니다. 중간 PNG는 `body_sequence`에 생성되고 배포 ZIP에는 포함하지 않습니다. 비교 영상은 별도 다운로드입니다.
