# 류시하 v5 — 어깨·배 연결부 수정

v4에서 팔·몸통이 따로 회전하며 어깨가 벌어지고, 몸통과 하체의 상대 이동으로 배 경계가 들려 보이던 문제를 수정한 버전입니다.

- 분리 전의 연결된 몸 그림을 사용합니다. 어깨·소매·배·허리를 하나의 연속된 표면으로 변형합니다.
- 팔 변형은 어깨에서 0으로 시작해 아래쪽으로 부드럽게 증가합니다. 상체 변형은 허리에서 갑자기 끊기지 않고 아래로 감쇠합니다.
- 16초 동작과 눈 깜빡임을 유지합니다. 몸은 30fps 투명 배경 영상으로 미리 렌더링하여 AE에서 파츠별 변환으로 다시 벌어지지 않도록 했습니다.
- 분리 전 그림을 사용하므로 v4에서 따로 복원된 어깨·의상·배의 세부 형태와 차이가 있습니다.

## AE 실행

1. 두 ZIP을 같은 위치에 압축 해제해 `Ryusiha_Natural_Motion_v5` 폴더를 합칩니다. `Connected_Body_v5_part1.mov`, `Connected_Body_v5_part2.mov`와 `assets` 폴더를 JSX 옆에 둡니다.
2. 파일 → 스크립트 → 스크립트 파일 실행에서 `Build_Natural_Motion_v5.jsx`를 실행합니다.
3. 새 `RYUSIHA_NATURAL_V5_16s` 컴포지션의 어깨와 허리를 16초 전체 확인합니다. 기존 v4 컴포지션은 변경되지 않습니다.
4. `Hair strength`로 머리카락 강도를 조절할 수 있습니다. 몸·팔·고개·눈 동작은 영상에 고정되어 있으며 변경하려면 다시 렌더링해야 합니다.
5. AEP 저장 후 MOV와 에셋도 함께 보관하세요. 배경 레이어를 끄면 투명 배경 출력이 가능합니다.

MOV 두 개는 알파 채널을 포함한 무손실 PNG 코덱, 각각 8초, 640×960, 30fps입니다. 스크립트가 0~8초와 8~16초에 이어 배치합니다. AE 캔버스는 1280×1920이며 몸 영상이 2배 확대되므로 v4의 개별 원본 파츠보다 확대 시 부드럽게 보입니다. 머리카락은 원본 PNG를 사용합니다.

## 검증·제한

미리보기와 몸 영상 두 개의 총 480프레임·16초, 전체 디코딩, 투명도, 정확한 시작/끝 포즈를 검사했습니다. 여러 동작 시점에서 어깨와 배 연결부를 시각적으로 확인했습니다. JSX 문법과 모의 AE 구성을 검사했지만 실제 After Effects 실행·렌더링은 이 환경에서 검증하지 못했습니다.

기존 그림의 색 테두리와 복원 품질은 남아 있습니다. 이번 수정은 움직일 때 연결부가 갈라지는 문제를 다룹니다. 완성된 Live2D 리깅이나 새 관절 원화를 제공하는 작업은 아닙니다.

## 재생성

Python 3, Pillow, NumPy, SciPy, FFmpeg 환경에서 `python3 render_preview.py`를 실행합니다. `body_sequence`에 중간 PNG 480장을 생성하고 전신 MP4와 연결된 몸 MOV 두 개를 만듭니다. PNG 중간 파일은 ZIP에 포함하지 않습니다. `motion.json`은 몸 동작 수식이며 머리카락 추종 수식은 JSX에도 포함됩니다.
