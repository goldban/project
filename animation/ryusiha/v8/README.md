# 류시하 v8 — 레퍼런스 초반의 대기 모션

제공된 NIKKE 레퍼런스의 앞부분 대기 장면을 기준으로 만든 12초 검토본입니다. 몸의 형태와 지지점을 유지하고 고개·팔·머리카락이 약간씩 다른 타이밍으로 움직이도록 구성했습니다. 중간의 무기 액션과 큰 자세 전환은 이 버전의 범위가 아닙니다.

## 방식 변경

v5~v7의 넓은 영역에 이동량을 직접 적용하던 변형을 관절 제약이 있는 2D 메시로 교체했습니다. 어깨·팔꿈치·손의 목표 위치를 연결하고, 메시의 국소 형태를 가능한 한 유지하는 ARAP 최적화로 중간 영역을 계산합니다. 머리·손 제어점은 형태를 유지하고 하체는 지지점으로 고정합니다. 머리카락은 고개를 따라간 뒤 작은 시간차로 흔들립니다.

이 방식도 완성된 Live2D/Spine 리깅을 대신하지 않습니다. 옷과 관절 사이에는 작은 변형이 남습니다. 큰 팔 자세 변경, 회전된 얼굴, 무기 동작을 만들려면 그 자세의 원화와 가려진 부분이 필요합니다.

두 ZIP을 같은 위치에 풀어 `Ryusiha_Natural_Motion_v8` 폴더를 합칩니다. 다음 파일들이 같은 폴더에 있어야 합니다.

```text
Build_Natural_Motion_v8.jsx
Connected_Body_v8_part1.mov
Connected_Body_v8_part2.mov
assets/
```

AE에서 JSX를 실행하고 새 `RYUSIHA_REFERENCE_V8_12s` 컴포지션을 확인하세요. 두 MOV는 각각 6초이며 자동으로 연결됩니다. `Hair strength`는 따로 조절할 수 있으며 몸 동작은 영상에 고정되어 있습니다. 배경 레이어를 끄면 투명 배경 출력이 가능합니다.

## 검증·제한

머리·손 제어점 사이의 거리가 유지되는지, 12초 루프가 이어지는지 검사했습니다. 하체 보호 영역의 픽셀이 전체 360프레임에서 동일한지, 두 MOV의 360프레임이 원본 RGBA와 일치하는지 검사했습니다. 영상 전체 디코딩과 JSX 문법·모의 AE 구성을 검사했습니다. 실제 AE 실행과 렌더링은 미검증입니다.

몸은 640×960, 30fps 무손실 PNG 코덱 MOV로 제공하며 1280×1920 AE 캔버스에서 확대됩니다. 사용 이미지는 v7 보정본이므로 일부 세부 묘사는 초기 원본과 다릅니다. 기존 눈 포즈와 파츠 가장자리의 잔여물은 남아 있습니다.

## 재생성

Python 3, NumPy, SciPy, Pillow, FFmpeg 환경에서 `python3 render_preview.py`를 실행합니다. 메시·관절 구성은 `rig.py`에 있습니다. 중간 PNG는 `body_sequence`에 생성되며 ZIP에 포함하지 않습니다. 참고 영상의 원본이나 오디오는 배포 파일에 포함하지 않습니다.
