# 류시하 자연스러운 대기 모션 v3

첨부된 AE 렌더 영상에서 지적한 깜빡임과 몸·팔의 대기 움직임을 수정한 검토용 버전입니다. v2 파일은 변경하지 않았습니다.

## 변경

- 뜬 눈 위에 감은 눈 패치를 불투명도로 겹치던 레이어를 제거했습니다. 눈 주변만 기하학적으로 변형한 25단계 머리 PNG를 사용합니다. 완전히 감긴 상태는 기존 감은 눈 그림으로 마무리합니다.
- 눈 감기 90ms, 감은 상태 25ms, 눈 뜨기 170ms로 비대칭 타이밍을 적용했습니다. 2.18초와 5.61초에 깜빡이고, 6.02초에는 이어지는 한 번의 깜빡임을 넣었습니다.
- 발 근처를 중심으로 작은 무게 이동, 상체 호흡과 흔들림, 고개의 지연 움직임을 연결했습니다. 좌우 팔과 머리카락은 서로 다른 위상으로 뒤따릅니다.
- 8초, 60fps 반복 구성입니다. AE 캔버스 1280×1920, 참고 영상 640×960입니다.
- 머리카락은 이번 버전에서 작은 레이어 회전으로 움직입니다. CC Bend It 플러그인은 필요하지 않습니다. 가닥별 물리 변형은 포함하지 않습니다.

- `Natural_Motion_v3_Preview.mp4`: 전신 참고 영상
- `Face_and_Shoulders_v3.mp4`: 눈·상체 확대 영상
- `Blink_poses.png`: 눈의 중간 상태 비교

## 사용

1. ZIP 전체를 압축 해제합니다. `assets`와 `blink` 폴더를 스크립트 옆에 그대로 둡니다.
2. After Effects의 파일 → 스크립트 → 스크립트 파일 실행에서 `Build_Natural_Motion_v3.jsx`를 실행합니다.
3. 새로 생성된 `RYUSIHA_NATURAL_V3_8s` 컴포지션을 재생합니다. 기존 v2 컴포지션은 자동 변경되지 않습니다.
4. `CONTROLS`에서 `Body and arms`, `Head motion`, `Hair strength`를 조절합니다. 기본 1이며 0.5~1.2 범위를 권장합니다. `Blink amount` 기본값은 100이며, 0이면 눈을 뜬 채 유지합니다.
5. AEP를 저장하고, 에셋과 blink 폴더도 함께 보관합니다. 배경 레이어를 끄면 투명 배경 출력이 가능합니다.

## 검증·제한

Python 렌더러로 실제 480프레임 MP4를 만들고 전체 디코딩, 프레임 수, 눈 포즈, 8초 루프의 동일한 시작/끝 상태를 검사했습니다. JSX 문법과 모의 AE API 구성을 검사했으며, 11개 표현식을 481개 시점에서 평가해 유한한 값, 깜빡임 열림/닫힘/열림, 루프 연결을 확인했습니다. 모의 검사는 AE의 실제 파일 가져오기·화면 합성·렌더링을 검증하지 않습니다. 실제 After Effects 실행 및 렌더링은 이 Linux 환경에서 검증하지 못했습니다. 제공 MP4는 별도 렌더러의 참고 영상이며 AE 최종 출력으로 확인해야 합니다.

눈 중간 상태는 원본 2D 그림의 기하학적 변형이며, 새로 그린 다단계 눈꺼풀이나 Live2D 리깅이 아닙니다. 시선 추적·입 모양·손가락·팔꿈치 리깅은 없습니다. 기존 파츠의 가장자리 잔여물과 가려진 부분 복원 품질은 유지되며 별도의 원화 보정이 필요할 수 있습니다.

## 재생성

Python 3 및 Pillow, NumPy, SciPy, FFmpeg가 있는 환경에서:

```sh
python3 render_preview.py
```

PNG 눈 포즈만 다시 만들려면 `python3 render_preview.py --poses-only`를 실행합니다. AE 실행에는 Python이나 FFmpeg가 필요하지 않습니다.
