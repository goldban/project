# 류시하 대기 모션 v4 — 16초, 동작 확대

v3 AE 렌더 영상에 대한 “너무 소심하게 움직인다”는 피드백을 반영했습니다. 기존 v1~v3는 보존했습니다.

## 바뀐 동작

- 길이: 8초 → **16초**, 60fps. 여러 주기의 움직임과 두 번의 포즈 강조 구간을 결합했습니다.
- 몸: 발 근처를 중심으로 한 무게 이동, 허리 위 상체의 기울임과 호흡을 확대했습니다.
- 고개: 기울임 폭을 키우고 3~5초, 10~12초 부근에 기울였다 돌아오는 변화를 넣었습니다.
- 팔: 좌우 팔의 흔들림을 확대하고 한쪽 팔이 조금 더 벌어지는 강조 동작을 추가했습니다. 어깨 기준 회전이며 팔꿈치를 굽히거나 손을 흔드는 동작은 아닙니다.
- 머리카락: 고개와 상체를 따라가며 서로 다른 시간차로 흔들립니다.
- 눈: v3의 25단계 눈 포즈를 유지하며, 16초에 맞춰 깜빡임을 재배치했습니다.

ZIP을 전부 압축 해제하고 `assets`, `blink` 폴더를 스크립트 옆에 그대로 둡니다. After Effects에서 파일 → 스크립트 → 스크립트 파일 실행으로 `Build_Natural_Motion_v4.jsx`를 실행합니다. 새 **`RYUSIHA_NATURAL_V4_16s`** 컴포지션을 16초 전체 재생한 뒤 AEP로 저장하세요. 기존 v3 컴포지션은 바뀌지 않습니다.

`CONTROLS`의 `Body and arms`, `Head motion`, `Hair strength` 기본값은 1입니다. v4의 1은 v3보다 큰 움직임입니다. 먼저 기본값으로 확인하고 필요하면 0.7~1.2에서 조절하세요. `Blink amount` 기본값은 100이며 0이면 눈을 뜬 채 유지합니다. 강도를 크게 올리면 파츠 연결부가 드러날 수 있습니다.

## 검증과 한계

참고 영상은 Python/Pillow/FFmpeg로 생성한 별도 렌더링입니다. AE 구성과 같은 동작 수식을 사용하지만 AE 실제 실행·렌더링은 검증하지 못했습니다. 실제 AE에서 연결부와 눈 포즈를 최종 확인해야 합니다. 비교 영상의 왼쪽은 사용자가 첨부한 v3 AE 영상의 반복, 오른쪽은 v4 참고 영상입니다.

16초·960프레임 영상의 전체 디코딩과 프레임 수, 0초/16초의 동일한 포즈, JSX 문법과 모의 API 구성을 검사했습니다. 표현식은 961개 시점에서 유한한 값과 루프 연결을 검사했습니다. 이 검사는 실제 AE 파일 가져오기와 렌더링을 대신하지 않습니다.

원본 2D 파츠에 기반한 회전·이동 애니메이션입니다. 시선 추적, 입 모양, 팔꿈치·손가락, 머리 가닥별 물리 리깅은 포함하지 않습니다. 기존 원화·파츠의 가장자리 잔여물과 복원 품질은 별도 보정 대상입니다.

## 참고 영상 재생성

Python 3, Pillow, NumPy, SciPy, FFmpeg가 있는 환경에서 `python3 render_preview.py`를 실행합니다. `motion.json`은 참고 렌더러의 동작 수식을 담으며 JSX에도 같은 수식이 내장되어 있습니다. JSON을 수동 수정한 경우 JSX에도 같은 변경을 반영해야 합니다. AE 실행 자체에는 Python이나 FFmpeg가 필요하지 않습니다.
