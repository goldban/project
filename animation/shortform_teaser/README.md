# 필름 배경 숏폼 v3 — 편집용 After Effects 패키지

[최신 20초 시안 보기](./character_teaser_film_v3.mp4?raw=true) · [편집용 전체 ZIP](./Editable_Teaser_Package.zip?raw=true)

사용자가 선택한 필름·단추·붉은 실 이미지를 참고해 **9:16으로 확장·재구성한 배경**입니다. 원본 이미지와 픽셀 단위로 동일하지 않습니다. 기존 캐릭터 배경은 `assets/background_character.png`에 보관했습니다.

1080×1920 출력 · 30fps · H.264/AAC · 20초. Python 시안은 720×1280으로 합성 후 확대 출력합니다. AE 컴포지션은 1080×1920입니다.

## After Effects에서 수정

1. **전체 ZIP을 다운로드하고 압축을 풉니다.** JSX와 `assets` 폴더를 같은 위치에 둡니다.
2. **파일 → 스크립트 → 스크립트 파일 실행**에서 `Build_Editable_Teaser.jsx`를 실행합니다.
3. `EDIT_ME_1080x1920_20s`를 엽니다.
4. `EDIT TITLE`, `EDIT RELEASE`, `EDIT DATE` 텍스트 레이어를 더블클릭해 작품명·개봉 문구·날짜를 입력합니다. 현재는 임시 문구입니다.
5. 각 자막은 독립 텍스트 레이어입니다. 레이어 양 끝으로 등장·퇴장 시간을, P/S/T의 키프레임으로 위치·크기·불투명도를 수정합니다.
6. `BACKGROUND` 이미지 레이어를 교체하거나 확대·이동할 수 있습니다. 필름·단추·실은 PNG 한 장으로 합쳐져 있어 개별 파츠 리깅은 포함하지 않습니다. 셰이프 색상은 Contents → Fill에서 바꿉니다.
7. `AUDIO` 레이어를 음소거하거나 원하는 음원으로 바꿉니다. 직접 합성한 15초 리듬이 15초 후 반복됩니다. 참고 영상 음원은 포함하지 않았습니다.
8. 한글 글꼴 Noto Sans CJK KR Bold를 사용합니다. 없으면 설치하거나 사용 가능한 한글 글꼴로 바꾸세요.
9. 출력 시 `DRAFT LABEL`을 끄고 **다른 이름으로 저장**으로 `.aep`를 저장합니다. `assets`도 함께 보관하세요.

## 영상 3개 교체

| 시간 | 구성 |
| --- | --- |
| 0–3.5초 | 도입 타이포 |
| 3.5–5.3초 | 단편영화 |
| 5.3–7.1초 | 다큐 |
| 7.1–8.9초 | 홍보 영상 |
| 8.9–13초 | 세 영상이 모이는 3분할 화면 |
| 13–15초 | 이 모든 영상을, 영화관에서 |
| 15–20초 | 작품명·개봉일 |

**현재 시안의 영상 슬롯은 실제 클립이 아닌 임시 화면입니다.**

- 실행 전 `assets/clip01.mp4`(단편영화), `clip02.mp4`(다큐), `clip03.mp4`(홍보 영상)를 넣으면 JSX가 자동으로 불러옵니다. 각각 최소 7초를 권장합니다. 원본 비율을 유지하며 16:9 슬롯을 꽉 채우므로 가장자리가 잘릴 수 있습니다. 영상 소리는 기본 음소거입니다.
- 실행 후에는 `VIDEO_01_단편영화`, `VIDEO_02_다큐`, `VIDEO_03_홍보 영상` 컴포지션을 열어 영상을 넣고 임시 텍스트·배경을 끕니다. 영상 크기·위치를 맞춥니다. 같은 소스가 단독 소개와 3분할 장면에 함께 반영됩니다. 짧은 클립은 반복하거나 시간을 조정하세요.
- `MONTAGE SOLO`, `MONTAGE TOGETHER` 레이어의 키프레임으로 배치를, `MESSAGE` 텍스트 레이어로 핵심 문구를 수정합니다.

## 검증과 재생성

Python 3, Pillow, NumPy, FFmpeg, Noto Sans CJK Bold가 필요합니다.

```sh
cd animation/shortform_teaser
python3 render_v3.py
```

MP4, 합성 WAV, 확인용 JPG가 같은 폴더에 생성됩니다. Python 시안은 임시 화면만 렌더링하며 실제 클립 합성은 AE에서 합니다. v3 MP4 전체 600프레임 디코딩을 확인했습니다.

JSX 문법·모의 레이어 구성·타임라인·파일 누락·생성 실패 시 정리와 ZIP 무결성을 검사했습니다. **실제 After Effects 실행·렌더링은 미검증**입니다. JSX는 MP4를 편집 가능한 AE 레이어로 재구성하므로 화면과 모션이 픽셀 단위로 동일하지 않습니다. 외부 플러그인은 필요 없으며, `.aep` 바이너리는 JSX 실행 후 저장해야 합니다.
