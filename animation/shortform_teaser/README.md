**현재는 실제 영상이 없는 임시 화면입니다.** 다음 중 하나로 교체하세요.

- **실행 전 자동 불러오기:** ZIP을 푼 뒤 `assets/clip01.mp4`(단편영화), `assets/clip02.mp4`(다큐), `assets/clip03.mp4`(홍보 영상)로 파일을 저장하고 JSX를 실행합니다. 각각 최소 7초 클립을 권장합니다. 원본 비율을 유지하며 16:9 화면에 꽉 채워 가장자리가 잘릴 수 있습니다. 영상 소리는 기본 음소거입니다. 실제 클립이 없으면 해당 슬롯만 임시 화면으로 만들어집니다.
- **실행 후 직접 편집:** 프로젝트 패널의 `VIDEO_01_단편영화`, `VIDEO_02_다큐`, `VIDEO_03_홍보 영상` 컴포지션을 열어 영상을 넣고 임시 텍스트와 배경을 끕니다. 화면을 채우도록 크기와 위치를 조절합니다. 같은 슬롯이 단독 장면과 3분할 장면에 함께 반영됩니다. 짧은 소스는 클립을 반복하거나 시간을 조정하세요.

`MONTAGE SOLO`와 `MONTAGE TOGETHER` 레이어에서 각 영상의 위치·크기·등장 타이밍을 조정하고, `MESSAGE` 텍스트 레이어에서 핵심 문구를 수정합니다. 20초 구성으로 늘어났으므로 기존 15초 MP4와 구분해주세요. 음원은 15초 후 반복되며 필요하면 별도 음원으로 교체하세요.

## After Effects에서 직접 수정

1. **전체 ZIP을 다운로드하고 압축을 풉니다.** JSX만 받으면 이미지와 음원이 없어 실행되지 않습니다.
2. After Effects의 **파일 → 스크립트 → 스크립트 파일 실행**에서 `Build_Editable_Teaser.jsx`를 실행합니다.
3. `EDIT_ME_1080x1920_20s` 컴포지션을 엽니다.
4. `EDIT TITLE`, `EDIT RELEASE`, `EDIT DATE` 텍스트 레이어를 더블클릭해 작품명·개봉 문구·날짜를 입력합니다. 다른 자막도 각각 독립 텍스트 레이어입니다.
5. 타임라인에서 레이어 양 끝을 드래그해 등장·퇴장 시간을 바꾸고, `P`(위치), `S`(크기), `T`(불투명도)의 키프레임을 이동해 모션을 수정합니다. 각 컷은 연속된 자막 레이어로 구성됩니다.
6. 셰이프 레이어의 Contents → Fill에서 색상을 바꿉니다. `02 ILLUSTRATION`은 배경 이미지 교체·크기·위치를 수정하는 레이어입니다.
7. `AUDIO` 레이어를 음소거하거나 원하는 음원으로 교체합니다. 한글 글꼴이 없으면 Noto Sans CJK KR Bold를 설치하거나 텍스트 레이어에서 사용 가능한 한글 글꼴을 선택합니다.
8. 내보낼 때 `DRAFT LABEL` 레이어를 끄고 **파일 → 다른 이름으로 저장**으로 `.aep`를 저장합니다. `assets` 폴더도 함께 보관하세요.

**수정 가능한 범위:** 자막, 작품명, 개봉일, 글꼴, 색상, 등장 시간, 위치·크기 키프레임, 도형, 배경 이미지 교체, 오디오. 캐릭터·팻말·구름은 배경 PNG 한 장에 합쳐져 있어 개별 파츠 수정이나 캐릭터 관절 애니메이션은 지원하지 않습니다.

JSX는 MP4의 구성을 편집 가능한 AE 레이어로 재구성한 버전이므로 픽셀 단위로 동일하지 않습니다. 외부 플러그인은 필요 없습니다. JSX 문법·모의 구성·파일 누락 처리는 검사했으며, **실제 After Effects에서 실행·렌더링한 결과는 미검증**입니다. `.aep` 바이너리는 제공하지 않으며 JSX 실행 후 직접 저장합니다.


새 v2는 20초, 기존 v1은 15초입니다. 9:16 · 1080×1920 · 30fps · H.264/AAC. 720×1280으로 합성 후 1080×1920으로 확대 출력합니다.

첨부 캐릭터를 바탕으로 만든 배경, 타이포 전환, 화면 확대, 직접 합성한 리듬으로 구성했습니다. 참고 영상과 그 음원은 포함하지 않았습니다. 캐릭터 자체의 관절 애니메이션은 포함하지 않습니다.

마지막 화면의 `[ 작품명 ]`, `개봉일 입력`, `YYYY.MM.DD`는 임시 표시입니다. 실제 작품명과 개봉일 확정 후 교체해야 합니다.

## 재생성

Python 3, Pillow, NumPy, FFmpeg, Noto Sans CJK Bold 폰트가 필요합니다.

```sh
cd animation/shortform_teaser
python3 render.py
```

동일 폴더에 MP4, 합성 WAV와 확인용 JPG가 생성됩니다. 기존 영상 450프레임, v2 영상 600프레임 전체 디코딩을 확인했습니다. v2는 `python3 render_v2.py`로 재생성합니다. Python 시안의 영상 슬롯은 임시 그래픽이며 실제 클립을 합성하지 않습니다. 실제 클립 편집은 아래 AE 워크플로를 사용하세요.
